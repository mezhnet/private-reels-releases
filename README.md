# Private Reels – Releases

Hier liegen die fertigen APKs der App **Private Reels** (privater Reels-Feed und Lesebibliothek für den eigenen Vault, Android).

Die App prüft beim Start über Firebase Remote Config, ob es hier eine neuere Version gibt, lädt die APK herunter, prüft die SHA-256-Prüfsumme und öffnet den Installer. Der Quellcode liegt in einem privaten Repository.

Jedes Release enthält genau eine Datei `private-reels-<version>.apk`, signiert mit dem Release-Schlüssel der App.
